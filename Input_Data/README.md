# Input data

Place the processed replication inputs required by the MATLAB model in this
directory.

Some underlying source datasets cannot be redistributed through the public
GitHub repository because of licensing or size restrictions. See the main
`README.md` for data sources and the Zenodo replication archive for the
replication material that can be distributed.

Do not change filenames or folder structure expected by the model unless the
corresponding MATLAB import routines are updated as well.
